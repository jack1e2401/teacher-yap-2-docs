# Nội dung từng bài

Mỗi bài là một JSON theo mẫu trong `../templates/`, chứa nội dung gốc đã trích xuất, tóm tắt, thông tin nguồn và trạng thái duyệt.

Chưa có nội dung SGK nào được nhập sẵn. Chạy công cụ nhập theo `../README.md`; app chỉ đọc các file JSON có `status: "reviewed"`. Các file Markdown trong thư mục này không được đưa vào ngữ cảnh AI.
